# 🌐 WebSite1

HTML, CSS, JavaScript를 활용하여 기업형 웹사이트의 레이아웃과 다양한 UI 요소를 구현한 웹 퍼블리싱 실습 프로젝트입니다.

메인 비주얼 영상, 뉴스 콘텐츠, 상품 슬라이더 등을 구성하고 PC와 모바일 환경에 맞게 반응형 웹 페이지를 제작하는 것을 목표로 합니다.

## 🖥️ Main Features

### 1. Header & Navigation
- 로고 및 상단 메뉴 구성
- Contact, Help, Login, Join 등 유틸리티 메뉴
- 주요 페이지 이동을 위한 내비게이션 메뉴
- 모바일 환경을 위한 햄버거 메뉴 UI

### 2. Main Visual
- HTML Video 태그를 활용한 메인 배경 영상
- 자동 재생 및 반복 재생 설정
- 메인 타이틀과 소개 문구 표시
- 상세 페이지 이동 버튼 구성

### 3. Recent News
- 뉴스 콘텐츠 영역 구성
- 이미지, 제목, 설명으로 이루어진 카드형 레이아웃
- 여러 개의 뉴스 콘텐츠 배치

### 4. Products Slider
- Swiper 라이브러리를 활용한 상품 슬라이더
- 이미지와 상품 정보 표시
- 슬라이드 형태의 콘텐츠 구성

### 5. Responsive Web
- 모바일 화면을 위한 별도 메뉴 구성
- 햄버거 메뉴 및 오버레이 UI
- 반응형 CSS를 통한 화면 크기별 레이아웃 조정

## 🎯 Goal

HTML의 시맨틱 태그를 활용하여 웹 페이지의 구조를 설계하고, CSS를 통해 각 영역의 디자인과 레이아웃을 구현하는 것을 목표로 합니다.

JavaScript를 활용한 모바일 메뉴와 Swiper 슬라이더 등 다양한 UI 요소를 적용하며, 반응형 웹 디자인의 기본 원리도 함께 익히고자 합니다.

## 📝 Notes

웹사이트의 전체 구조를 직접 작성하고 CSS 파일을 기능별로 분리하여 관리하는 방식으로 실습했습니다.

단순한 정적 페이지 구성에서 나아가 영상, 슬라이더, 모바일 메뉴 등 다양한 요소를 활용하면서 실제 웹사이트의 레이아웃과 동작 방식을 익히는 데 집중했습니다.
